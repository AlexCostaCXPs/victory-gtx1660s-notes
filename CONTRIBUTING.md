# Como contribuir / How to contribute

## Português

Este repositório guarda notas de testes, não código do jogo. Contribuições úteis:

1. **Envie uma configuração testada** pelo modelo de issue "Relato de teste". Inclua: placa, RAM, versão do Windows, build do Victory (tag ou commit), variáveis `VICTORY_*` usadas e o resultado (FPS, ms por quadro, queda e tempo até cair).
2. **Anexe o log e o crash log** da sessão, sem caminhos pessoais e sem arquivos do jogo.
3. **Não envie** arquivos do jogo, cache de shaders, executáveis nem chaves.
4. **Mantenha a licença:** o material segue GPL v3 (ver `LICENSE`).
5. **Use o mesmo formato** da tabela de configurações em `README.md`, para comparar resultados.

## English

These notes store test results, not game code. Useful contributions:

1. **Send a tested configuration** with the "Test report" issue template. Include: GPU, RAM, Windows version, Victory build (tag or commit), the `VICTORY_*` variables used, and the result (FPS, ms per frame, crash and time until it crashed).
2. **Attach the log and the crash log** of the session, without personal paths and without game files.
3. **Do not send** game files, shader cache, executables or keys.
4. **Keep the license:** the material is under GPL v3 (see `LICENSE`).
5. **Use the same format** as the configuration table in `README.md`, so results can be compared.
